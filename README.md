# FlightCase Hub

Профессиональная фурнитура для производства флайткесов и рэковых стоек.

## Технологический стек

- **Next.js 15** (App Router, Turbopack)
- **TypeScript**
- **Tailwind CSS** (Минималистичный B2B дизайн)
- **Prisma** (ORM)
- **SQLite** (Локальная база данных)
- **Zustand** (Управление состоянием корзины)

## Инструкция по установке и запуску (Linux/Ubuntu/Proxmox)

### 1. Установка зависимостей

Убедитесь, что у вас установлен Node.js (рекомендуется v18+).

```bash
npm install
```

### 2. Инициализация базы данных

Создайте файл базы данных SQLite, примените схему и наполните её начальными данными:

```bash
# Инициализация схемы БД
npx prisma db push

# Наполнение начальными данными (категории и товары)
npx ts-node prisma/seed.ts
```

### 3. Настройка переменных окружения

Убедитесь, что файл `.env` содержит необходимые настройки:

```env
DATABASE_URL="file:./dev.db"
ADMIN_PASSWORD="admin"
```

### 4. Запуск в режиме разработки

```bash
npm run dev
```

### 5. Сборка и запуск в режиме продакшена

Для достижения максимальной производительности соберите проект:

```bash
# Сборка проекта
npm run build

# Запуск сервера
npm run start
```

## Админ-панель

Доступ к управлению товарами и заказами осуществляется по адресу `/admin`.
Пароль по умолчанию: `admin` (настраивается в `.env`).

### Основные возможности админки:
- Просмотр статистики заказов.
- Управление товарами (Добавление, Редактирование, Удаление).
- Загрузка изображений (сохраняются локально в `public/uploads`).
- Автоматическая генерация URL-адресов (slug) из названий на русском языке.
